# 🤖 RUSSIA DEV AI

**RUSSIA DEV AI** — AI-помощник для разработки RP-проектов и игровых систем.

## 🚀 Возможности

* 💻 Генерация кода
* 🧩 Создание игровых систем
* 🔍 Анализ и поиск ошибок в коде
* 📁 Генерация файлов проекта
* 🗄️ Работа с SQL и базами данных
* 🤖 AI-ассистент для разработчика
* 📦 Подготовка готовых модулей проекта

## 🛠️ Технологии

* Python
* FastAPI
* AI API
* SQLite / MySQL
* Telegram Bot
* GitHub

## 🎯 Цель проекта

Создать удобного AI-помощника, который сможет помогать разработчикам RP-проектов создавать, анализировать и исправлять код.
